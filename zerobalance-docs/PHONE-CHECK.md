# ZeroBalance 폰 확인 체크리스트 (약 10분)

PC에서 폰 크기를 흉내 낸 가상 브라우저로는 모두 확인했지만, **실제 폰에서는 아직 확인하지 못했어요.**
아이폰이든 안드로이드든, **쓰실 폰으로** 위에서부터 차례로 해 보세요. 각 줄 끝의 ✅ 기대 결과와 다르면 ❌로 표시해 주세요.

- 주소: https://zerobalance-salon.vercel.app/app/
- 시작 전: 홈 화면에 예전 CLOSING 아이콘이 있으면 지우세요.

## A. 설치 (2분)
1. 폰 브라우저(아이폰은 **Safari**, 안드로이드는 **Chrome**)로 위 주소를 엽니다.
   ✅ 남색 큰 카드와 ZB 로고가 보이고, 글자가 깨지지 않는다.
2. **홈 화면에 추가** (아이폰: 공유 버튼 → 홈 화면에 추가 / 안드로이드: 메뉴 → 홈 화면에 추가)
   ✅ 홈 화면에 **ZB 아이콘**과 `ZeroBalance` 이름이 생긴다. (예전 아이콘이 아니다)
3. 방금 만든 **홈 화면 아이콘으로** 앱을 엽니다. 앞으로는 이 아이콘으로만 쓰세요.
   ✅ 주소창 없이 앱처럼 전체 화면으로 열린다.

## B. 입력 (3분)
4. 홈의 **예시 데이터로 둘러보기**를 누릅니다.
   ✅ 숫자가 채워지고, 아래 탭 5개가 보이고, 맨 아래 탭이 가려지지 않는다.
5. 위쪽 **‹ ›** 로 달을 바꿔 봅니다.
   ✅ 한 번 눌러서 잘 바뀐다. (손가락으로 누르기 불편하면 ❌)
6. **입력 › 오늘 마감**에서 카드 칸에 `1234567`을 입력합니다.
   ✅ 숫자 키패드가 뜨고, 입력하는 동안 `1,234,567`처럼 쉼표가 자동으로 붙는다.
7. **오늘 마감**의 날짜 달력에서 다른 날을 눌러 봅니다.
   ✅ 그 날짜로 바뀌고 금액을 넣을 수 있다.

## C. 급여·이미지 (2분)
8. **급여** 탭에서 직원 한 명을 눌러 펼치고 **정산내역 보내기 › 이미지로 보내기**를 누릅니다.
   ✅ 공유 창이 열린다(카톡 등 선택 가능). 공유 창이 안 열리고 이미지가 화면에 뜨면, 길게 눌러 저장되는지 확인.
   ✅ 이미지 아래에 로고(ZB + ZERO BALANCE)가 선명하게 나온다.

## D. 백업 (2분)
9. **더보기 › 기기 맞추기 · 백업 › 이 폰 기록 보내기**를 누릅니다.
   ✅ 공유 창이 열려 카톡 나에게 보내기·파일 저장을 고를 수 있다.
10. 방금 저장한 파일을 같은 화면의 **받은 파일 열기**로 불러옵니다.
    ✅ "이 파일과 합칠까요?" 안내가 나온다. (이미 같은 내용이면 "합칠 게 없어요")
    (아이폰은 카톡으로 받은 파일을 먼저 '파일' 앱에 저장해야 고를 수 있어요.)

## E. 문의 · 잠금 (2분)
11. **더보기 › 문의 · 개선 제안**에서 내용을 쓰고 **내용 복사하고 인스타 DM 열기**를 누릅니다.
    ✅ 인스타그램 DM 창이 열리고, 대화창에 **붙여넣기**를 하면 방금 쓴 내용이 나온다.
    ❌ 붙여넣기가 안 되면 알려 주세요. (아이폰에서 복사가 막히는 경우가 있어요)
12. **설정 › 잠금**에서 비밀번호 4자리와 힌트를 정하고 **잠금 켜기**. 앱을 닫았다가 다시 엽니다.
    ✅ 숫자 키패드 잠금 화면이 뜨고, 맞게 누르면 열린다. "비밀번호를 잊었어요"를 누르면 내가 적은 힌트가 보인다.

## F. 새로 넣은 기능 (2분)
13. **더보기 › 세무사에게 보낼 엑셀**을 누릅니다.
    ✅ 공유 창이 뜨고(카톡·메일·파일 저장), 받은 파일을 엑셀이나 구글 시트로 열면 한글이 깨지지 않고 월별 요약·직원 급여·지출 내역이 보인다.
14. **설정 › 화면 글자 크기 › 크게**를 누르고 홈·입력·급여 화면을 둘러봅니다.
    ✅ 글자가 커지고, 화면 옆으로 잘리거나 가로로 밀리는 곳이 없다.
15. 홈의 **이번 달 목표 매출 정하기**를 눌러 목표를 넣습니다.
    ✅ 홈에 달성률 막대와 "남은 ○일 동안 하루 평균 ○만원" 안내가 나온다.

## 문제가 있으면 이렇게 알려 주세요
- 폰 종류와 OS 버전 (예: 아이폰 14, iOS 18.2 / 갤럭시 S23)
- 몇 번 항목에서 어떻게 달랐는지 (화면 캡처가 있으면 가장 좋아요)
- 홈 화면 앱으로 열었는지, 브라우저로 열었는지

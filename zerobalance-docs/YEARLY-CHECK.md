# 해마다 점검할 숫자 (ZeroBalance)

세금·보험 숫자는 해마다 바뀌어요. **12월 말~1월 초에** 새 해 공고를 확인하고 아래를 고치세요.
코드 위치는 `zerobalance/app/index.html` 기준이에요 (줄 번호는 바뀔 수 있어서 이름으로 찾으세요).

## 고친 뒤 할 일
1. 설정 화면의 안내 문구(카드 수수료율 구간 등)와 `aidSave()`의 절세 문구도 같이 맞추기
2. 테스트 모음 전부 돌리기 → 커밋 → 배포
3. `tools/make_trial.py` 로 체험판 다시 만들기 (쓰고 있다면)
4. 개인정보·이용 안내(`zerobalance/privacy/index.html`)의 시행일 고치기

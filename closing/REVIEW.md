# CLOSING 리디자인 · 사용자 관점 검토

레퍼런스(FILO 랜딩) 스타일을 적용했습니다: 네이비 그라데이션 히어로, 흰 둥근 카드, 블루 포인트, Pretendard, 선형 아이콘, 소제목(파란 eyebrow) + 큰 제목.
계산 로직(매출·급여·세금·백업·AI)은 그대로 두고, 화면과 문구만 바꿨습니다.

## 고친 버그
1. **처음 열 때 하단 탭에 선택 표시가 없음** — `ui.tab` 초기값이 없었음. `home`으로 지정.
2. **예시 데이터로 실제 기록이 지워질 수 있음** — 이번 달만 비어 있으면 '예시로 둘러보기'가 보였고, '예시 지우기'는 모든 달 기록을 삭제했음. 이제 기록이 하나도 없을 때만 예시를 불러옴.

## 뺀 것 / 합친 것
- 설정 화면의 **중복 카드**(의견 보내기, 백업·복원) 제거 → 더보기에만 둠
- **대표자** 입력칸 제거 (앱 어디에서도 쓰이지 않음, 저장된 값은 유지)
- 홈의 '매출 100원은 어디로' 막대 + 표 → **도넛 + 범례**로 압축 (세금 탭 '돈의 흐름'과 겹치던 부분 정리)
- 오늘 마감의 **날짜 입력 + 일별 기록 목록** → **마감 달력** 하나로 통합
- 입력 현황 체크리스트는 다 채우면 자동으로 숨김
- 화면 상단의 'CLOSING' 큰 글자(영수증 스킨) → 헤더 로고로 대체

## 추가한 것
- 홈 **히어로**: 세후 남는 돈 + 4칸 요약(총매출·전월 대비, 지출, 인건비, 세금 적립)
- **오늘 마감 상태 카드**: 입력 여부를 한눈에, 바로 입력/수정
- **최근 7일 매출** 막대그래프 (오늘 마감 기록 기준, 일 평균)
- **다가오는 세금 일정** D-day: 원천세(매달 10일, 예상액), 부가세(일반 1·4·7·10월 25일 / 간이 1월 25일), 종합소득세(5월 31일)
- 첫 사용자용 **시작하는 법 STEP 1~3**
- 더보기 **자주 묻는 질문** 6개, 의견 보내기 배너, 하단 푸터
- 금액 입력 중 **실시간 1,000단위 쉼표**
- 직원 카드 **이니셜 아바타**, 정산내역 **아래에서 올라오는 시트**
- **정산 이미지** 새 디자인 (네이비 헤더 + 블루 입금액 박스)
- 데스크톱(1024px+): 2단 카드 + 떠 있는 하단 탭
- **손님 수 · 객단가**: 오늘 마감에 '손님 수' 칸, 홈에 객단가 카드(전월 대비, 이번 달 손님, 하루 평균). 월 매출 화면에 이번 달 손님 수를 직접 넣을 수도 있음. AI 상담에도 객단가 전달

- **기기 맞추기 (반자동 동기화)**: 더보기 › 기기 맞추기 · 백업
  - 보내기: 지금 기기 기록을 파일로 (카톡 나에게 보내기·파일 앱). 백업도 같이 됨
  - 받은 파일 열기: 통째로 덮어쓰지 않고 **날짜별로 합침**. 합치기 전에 '새 날짜 n일 · 고친 날짜 · 지운 날짜 · 직원 · 지출 목록 · 설정' 미리보기
  - 규칙: 기록 단위(날짜 하루, 월 직접 입력분, 매입 목록, 경비 목록, 직원, 직원별 월 급여 입력, 설정)마다 고친 시각을 저장하고, 양쪽이 다르면 더 나중에 고친 쪽을 남김. 지운 것도 전달됨
  - 이번 업데이트 전에 입력한 기록은 고친 시각이 없어서, 양쪽이 다르면 합치는 기기 쪽을 남김 (한쪽이 비어 있으면 있는 쪽을 가져옴)
  - 기존 '통째로 바꾸기'는 미리보기 화면 아래 링크로 남김. 예시 데이터 파일은 합치지 않음
  - 테스트 14개 통과: 첫 합치기, 왕복, 같은 날 양쪽 수정, 삭제 전달, 같은 파일 반복, 화면 흐름, 예시 거부

- **올해 누적**: 세금 탭 [이번 달 | 올해 누적] 전환, 홈에 누적 요약 카드(2개월 이상 기록 시)
  - 누적 남는 돈·매출·지출·인건비·쌓아 둘 세금, 달마다 막대 + 월별 목록(누르면 그 달로 이동)
  - 종합소득세: 기록한 달의 월평균 × 12로 1년 추정, 지금까지 쌓아 둘 몫 = 1년 세액 × 기록한 달/12
  - 부가세: 일반은 상·하반기, 간이는 1년 단위. 카드 발행세액공제 연 1,000만원 한도를 한 번만 적용
  - 누적 손님 수·평균 객단가

## 다음에 검토해 볼 제안 (아직 안 만듦)
- **카드 매출 입금 예정일**: 카드사별 정산 주기로 '이번 주 들어올 돈'
- **자동 동기화**: 지금은 반자동(파일로 합치기). 판매 단계에서는 구글 드라이브(각자 드라이브에 보관) 또는 서버 + 기기 안 암호화 방식 검토
- **세금 기준 연도 점검**: 카드 발행세액공제 1.3%·연 1,000만원은 코드상 2026년 12월 31일까지 기준. 2027년 1월 전에 개정 내용 확인 필요
- **AI 모델 이름**(`gemini-3.8-flash`): 지금도 유효한 이름인지 확인하지 않았음

## 배포 시 확인
- `--tab-lift: 52px` — 원래 코드처럼 하단 탭을 'Powered by Netlify' 배지 위로 올림. 배지가 없으면 `0px`로 바꾸면 화면이 넓어짐
- Pretendard 폰트는 jsdelivr CDN에서 불러옴. 오프라인이면 기기 기본 글꼴로 표시됨
- `manifest.webmanifest`, 아이콘, `sw.js` 경로는 기존 그대로

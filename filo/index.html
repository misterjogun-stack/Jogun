기능

재고조사에 필요한 건 다 들어 있습니다

현직 헤어 디자이너가 매장 약장을 관리하면서 필요했던 기능만 넣었습니다. 엑셀로 정리해 둔 목록이 있다면 그대로 올려서 시작하세요.

상품 등록 · 엑셀 업로드

한 개씩 등록하거나, 정리해 둔 엑셀을 올려 한 번에 등록합니다. 이미 있는 품목은 바뀐 값만 고쳐요.

바코드 스캔

폰 카메라로 바코드를 찍으면 품목을 바로 찾습니다. 블루투스·USB 바코드 스캐너도 그대로 쓸 수 있어요.

실물 재고 수량 입력

스캔한 품목의 실물 수량을 + − 로 맞추거나 숫자로 입력합니다. 전산과 같으면 '일치' 한 번이면 끝.

전산 · 실물 자동 비교

조사 시작 순간의 전산 재고를 기록해 두고, 실물 수량을 넣는 즉시 비교합니다.

재고 차이 자동 표시

모자라면 빨간색 −, 남으면 파란색 + 로 표시됩니다. '차이 있음'만 모아 볼 수도 있어요.

조사 진행률 확인

전체 항목, 조사 완료, 미조사 개수와 진행률이 실시간으로 보입니다. 홈 화면에서도 이어서 조사할 수 있어요.

결과 엑셀 · PDF 다운로드

조사 결과를 엑셀 파일로 받거나 PDF로 저장해 보관하고 공유하세요. 요약 시트도 함께 들어갑니다.

빠른 차감 · 발주 문자

평소엔 꺼낼 때 − 한 번. 적정선 아래로 내려간 약은 거래처별 발주 문자로 정리됩니다.

바코드 재고조사

차이는 알아서 나옵니다

  • 폰 카메라로 바코드를 비추면 품목이 바로 뜹니다
  • 실물 수량을 맞추고 '등록하기'를 누르면 다음 약으로 넘어갑니다
  • 등록되지 않은 바코드는 그 자리에서 새 품목으로 추가할 수 있어요
  • 조사를 마치면 실물 수량을 재고에 반영할지 고를 수 있습니다

시작하는 법

세 단계면 재고조사가 끝납니다

  1. 품목 등록

    엑셀 양식에 제품명, 바코드, 현재고, 적정선을 정리해 올리거나 앱에서 하나씩 등록합니다.

  2. 재고조사 생성 · 스캔

    '재고조사 생성'을 누르고 약장을 돌며 바코드를 찍어 실물 수량을 넣습니다.

  3. 차이 확인 · 결과 저장

    차이 난 품목을 확인하고 조사를 완료한 뒤, 결과를 엑셀이나 PDF로 저장합니다.

자주 묻는 질문

궁금한 점

앱을 설치해야 하나요?

아니요. 폰 브라우저에서 링크를 열면 바로 쓸 수 있습니다. 브라우저 메뉴의 '홈 화면에 추가'를 누르면 앱처럼 아이콘이 생깁니다.

회원가입이나 비용이 있나요?

없습니다. 가입 없이 열자마자 쓸 수 있습니다.

제 데이터는 어디에 저장되나요?

원장님 폰(브라우저) 안에만 저장되고 서버로 보내지 않습니다. 대신 폰을 바꾸거나 브라우저 기록을 지우면 사라질 수 있으니, 설정의 '전체 백업'으로 파일을 받아 카톡 '나에게 보내기' 등에 보관해 주세요.

폰을 바꾸면 어떻게 하나요?

예전 폰에서 받은 백업 파일을 새 폰에서 설정 → '백업 복원'으로 열면 약제, 거래처, 발주 이력이 그대로 돌아옵니다.

바코드 스캐너 기기도 쓸 수 있나요?

네. 블루투스나 USB 바코드 스캐너는 키보드처럼 번호를 입력해 주기 때문에, 스캔 화면의 번호 입력 칸에서 그대로 쓸 수 있습니다. 카메라 권한을 허용하지 않아도 됩니다.

바코드가 없는 약은요?

바코드는 선택 항목입니다. 재고조사 목록에서 제품명으로 찾아 실물 수량을 직접 입력하면 됩니다.

엑셀은 어떤 형식으로 올리나요?

첫 줄에 제품명, 바코드, 카테고리, 거래처, 전화번호, 현재고, 적정선 같은 제목을 넣으면 됩니다. 제품명만 필수이고, 앱의 '엑셀 양식 받기'로 빈 양식을 받을 수 있어요. 올리기 전에 추가·변경될 내용을 미리 보여 줍니다.

PDF는 어떻게 저장하나요?

재고조사 화면의 'PDF 저장'을 누르면 결과 보고서가 열리고 인쇄 창이 뜹니다. 프린터 대신 'PDF로 저장'을 고르면 됩니다.

직원들과 같이 쓸 수 있나요?

지금은 기기마다 기록이 따로 저장됩니다. 약장 옆에 매장 공용 폰이나 태블릿 한 대를 두고 같이 쓰시는 방식을 권합니다.

문자는 자동으로 나가나요?

아니요. ZEROCOUNT는 문자 내용만 만들어 두고, 전송 버튼을 누르면 폰의 문자 앱이 열립니다. 내용을 확인하고 원장님이 직접 보내시면 됩니다.

샘플 약제와 체험용 바코드가 미리 들어 있어서, 1분이면 재고조사부터 결과 엑셀까지 확인할 수 있습니다.

# 손가락 피아노

카메라로 아이의 두 손을 인식해서, 화면 속 손가락이 건반에 닿으면 피아노 소리가 나는 놀이입니다. 파일 하나(`index.html`)로 되어 있고 설치가 필요 없습니다.

## 여는 방법

- **주소**: https://finger-piano.vercel.app (Vercel 프로젝트 `finger-piano`, 저장소와 자동 배포는 연결하지 않았으므로 고친 뒤에는 다시 배포해야 합니다)
- **컴퓨터**: `index.html` 을 크롬으로 엽니다(파일을 크롬 창에 끌어다 놓기). 카메라 허용 창이 뜨면 허용합니다.
- **인터넷 주소로 쓰기**: Vercel, Netlify Drop 같은 곳에 이 폴더를 올리면 https 주소가 생기고, 태블릿·휴대폰에서도 열 수 있습니다. 카메라는 https 주소에서만 켜집니다.
- 처음 켤 때 손 인식 프로그램(MediaPipe, 약 8MB)을 인터넷에서 받으므로 10초쯤 걸립니다.

## 노는 법

- **놓는 방법**: 휴대폰·태블릿은 손에 들지 말고 가로로 세워 두고, 1미터쯤 떨어져 앉습니다.
- **손가락 접기(기본)**: 손바닥이 화면을 보게 손을 들면 손 아래 흰 건반 5개에 손 색 그림자와 손가락 번호(엄지 1 ~ 새끼 5)가 생깁니다. 손가락 끝마다 그 손가락이 맡은 음 이름이 붙고, 손가락을 접으면 그 건반이 울립니다. 손을 좌우로 옮기면 건반 묶음이 따라 움직입니다(손가락을 접고 있는 동안에는 고정).
- **건반까지 내리기**: 예전 방식. 손가락 끝을 화면 아래 건반까지 내리면 울립니다. 검은건반도 칠 수 있습니다.
- **노래 따라치기**: 노란 별이 있는 건반을 차례로 누르면 노래가 완성됩니다. 손가락 접기에서는 칠 건반을 맡은 손가락 끝에 노란 고리가 생깁니다. 「들어보기」로 먼저 들을 수 있습니다. 작은 별, 나비야, 비행기, 환희의 송가(모두 저작권이 끝난 옛 선율, 가사 없이 계이름만 표시).
- **설정**: 누르기 방식, 건반 수(61건반 C2~C7 / 3옥타브 / 2옥타브), 손 색 바꾸기. 세로 화면에서는 처음에 2옥타브로 시작합니다.
- 화면에서 가장 크게 보이는 손 두 개만 쓰고, 뒤에 있는 사람의 작은 손은 무시합니다.
- 카메라 없이도 마우스·터치로 칠 수 있고, 키보드 A~; 줄(W, E, T, Y, U, O, P 는 검은건반)로도 칩니다.

## 고칠 때

- 손가락을 접었다고 보는 기준은 `index.html` 의 `foldScore`, `PRESS_AT`, `RELEASE_AT` 에서 조절합니다.
- 건반 범위는 `index.html` 위쪽의 `RANGES` 에서 바꿉니다. 61건반은 `{ lo: 36, hi: 96 }` (MIDI 번호 36 = 낮은 도).
- 노래는 `SONGS` 에 `"C4 D4 E4:2"` 처럼 음이름과 박자를 적어 넣습니다.
- 화면이나 카메라 영상은 어디에도 보내지 않고 브라우저 안에서만 처리합니다.

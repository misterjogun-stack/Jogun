# 손가락 피아노

카메라로 아이의 두 손을 인식해서, 화면 속 손가락이 건반에 닿으면 피아노 소리가 나는 놀이입니다. 파일 하나(`index.html`)로 되어 있고 설치가 필요 없습니다.

## 여는 방법

- **컴퓨터**: `index.html` 을 크롬으로 엽니다(파일을 크롬 창에 끌어다 놓기). 카메라 허용 창이 뜨면 허용합니다.
- **인터넷 주소로 쓰기**: Vercel, Netlify Drop 같은 곳에 이 폴더를 올리면 https 주소가 생기고, 태블릿·휴대폰에서도 열 수 있습니다. 카메라는 https 주소에서만 켜집니다.
- 처음 켤 때 손 인식 프로그램(MediaPipe, 약 8MB)을 인터넷에서 받으므로 10초쯤 걸립니다.

## 노는 법

- **자유 연주**: 손가락 끝(동그라미)을 화면 아래 건반까지 내리면 그 건반이 울립니다. 왼손은 하늘색, 오른손은 주황색입니다. 빨리 내리면 소리가 조금 더 커집니다.
- **노래 따라치기**: 노란 별이 있는 건반을 차례로 누르면 노래가 완성됩니다. 「들어보기」로 먼저 들을 수 있습니다. 작은 별, 나비야, 비행기, 환희의 송가(모두 저작권이 끝난 옛 선율, 가사 없이 계이름만 표시).
- **건반 수**: 61건반(C2~C7) / 3옥타브 / 2옥타브. 61건반은 건반이 좁아서 어린아이에게는 2옥타브가 훨씬 쉽습니다.
- **검지만**: 손을 내릴 때 여러 손가락이 한꺼번에 울리면 검지만 쓰도록 바꿉니다.
- **왼손·오른손 바꾸기**: 색이 반대로 보이면 누릅니다.
- 카메라 없이도 마우스·터치로 칠 수 있고, 키보드 A~; 줄(W, E, T, Y, U, O, P 는 검은건반)로도 칩니다.

## 고칠 때

- 건반 범위는 `index.html` 위쪽의 `RANGES` 에서 바꿉니다. 61건반은 `{ lo: 36, hi: 96 }` (MIDI 번호 36 = 낮은 도).
- 노래는 `SONGS` 에 `"C4 D4 E4:2"` 처럼 음이름과 박자를 적어 넣습니다.
- 화면이나 카메라 영상은 어디에도 보내지 않고 브라우저 안에서만 처리합니다.

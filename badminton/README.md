# 손 배드민턴

카메라로 손을 인식해서, 손을 휘두르면 라켓이 셔틀콕을 치는 배드민턴 게임입니다. 상대는 AI 선수 "콕봇"입니다. 파일 하나(`index.html`)로 되어 있고 설치가 필요 없습니다.

## 여는 방법

- **주소**: https://hand-badminton.vercel.app (Vercel 프로젝트 `hand-badminton`, 저장소와 자동 배포는 연결하지 않았으므로 고친 뒤에는 다시 배포해야 합니다)
- 휴대폰·태블릿은 가로로 세워 두고 2미터쯤 떨어져 섭니다. 팔을 크게 휘둘러도 손이 화면에 보여야 합니다.
- 처음 켤 때 손 인식 프로그램(MediaPipe, 약 8MB)을 받으므로 10초쯤 걸립니다. 카메라는 https 주소에서만 켜집니다.

## 노는 법

- 선수는 셔틀콕 쪽으로 저절로 뛰어갑니다. 셔틀콕 둘레의 동그라미가 초록색이 되면 손을 휘두릅니다. 조금 일찍 휘둘러도 잠깐 기억해 두었다가 칩니다(쉬움일수록 넉넉함).
- **기술**: 위로 휘두르면 클리어(높고 멀리), 높은 공을 위에서 아래로 내려치면 스매시, 옆으로 세게 휘두르면 드라이브, 살짝 휘두르면 드롭(네트 앞). 낮은 공을 위로 올리면 높이 띄우기.
- **방향**: 휘두를 때 손이 화면 왼쪽에 있으면 왼쪽, 오른쪽에 있으면 오른쪽으로 날아갑니다.
- **서브**: 위로 크게 휘두르면 롱 서브, 작게 휘두르면 숏 서브. 점수가 짝수면 오른쪽, 홀수면 왼쪽에서 대각선으로 서브합니다.
- 밖으로 나갈 공은 선수가 받지 않고 그냥 둡니다("아웃 같아요" 표시). 떨어진 자리에는 인/아웃 표시가 잠깐 남습니다.
- 랠리 포인트 방식, 5점·11점·21점 중 먼저 도달하면 이깁니다(듀스 없음).
- 마우스·터치: 빠르게 휘두르거나 화면을 누릅니다(위쪽 1/3을 누르면 스매시). 키보드: 스페이스(높게), X(스매시), Z(살짝).

## 난이도

| | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 콕봇 이동 속도 | 느림 | 보통 | 빠름 |
| 콕봇 실수 | 자주 | 가끔 | 드물게 |
| 칠 수 있는 범위·기억 시간 | 넓음 | 보통 | 좁음 |
| 내 공이 밖으로 나감 | 안 나감 | 가끔 | 자주 |

85% 정도 맞히는 자동 선수로 11점 경기를 돌려 보면 쉬움 11:5~11:7(승), 보통 5:11, 어려움 1:11 정도가 나옵니다.

## 고칠 때

- 난이도 값은 `index.html` 위쪽 `DIFF` 에 있습니다.
- 셔틀콕 물리는 실제 코트 규격(13.4m × 5.18m, 네트 1.55m)과 공기 저항 `DRAG` 로 계산합니다.
- 카메라 영상은 어디에도 보내지 않고 브라우저 안에서만 처리합니다.

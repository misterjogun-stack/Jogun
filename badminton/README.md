# 손 배드민턴 (HAND BADMINTON)

카메라로 몸(어깨·팔꿈치·손목)을 인식해서, 팔을 휘두르면 3D 선수가 셔틀콕을 치는 배드민턴 게임입니다. 상대는 AI 선수 KENTA입니다.

## 여는 방법

- **주소**: https://hand-badminton.vercel.app (Vercel 프로젝트 `hand-badminton`. 저장소와 자동 배포는 연결하지 않았으므로 고친 뒤에는 다시 배포해야 합니다)
- 휴대폰·태블릿은 가로로 세워 두고 2미터쯤 떨어져 섭니다. 상체와 팔이 화면에 다 보여야 합니다.
- 처음 켤 때 3D 엔진(three.js)과 몸 인식 프로그램(MediaPipe Pose, 약 6MB)을 받으므로 10초쯤 걸립니다. 카메라는 https 주소에서만 켜집니다.
- 여러 파일(ES 모듈)로 되어 있어서 `index.html` 을 파일로 바로 열면 동작하지 않습니다. 웹 주소로 열거나, 이 폴더에서 `python3 -m http.server` 로 띄워서 엽니다.

## 화면 구성 (중계 화면 스타일)

- 왼쪽 위 **HAND TRACKING**: 카메라 화면에 몸 뼈대와 라켓 손 표시. 휘두르면 손 표시가 연두색으로 번쩍입니다.
- **SPEED**: 마지막으로 친 셔틀콕의 처음 속도(km/h). 세게 내려친 스매시는 300km/h 넘게 나옵니다.
- **점수판**: 국기, 이름, 점수(앞선 쪽 파란 칸), 서브하는 쪽 연두 점, SET 번호와 게임 스코어.
- 오른쪽 **SMASH · CLEAR · DROP** 카드: 친 기술이 빛납니다. 칠 수 있을 때 테두리가 밝아지고, 마우스·터치로 눌러서 칠 수도 있습니다.
- 바닥의 **파란 원**: 상대 공이 떨어질 자리. 빨간 원이면 밖으로 나가는 공이니 그냥 둡니다.

## 노는 법

- 선수는 셔틀콕 쪽으로 저절로 달려갑니다. 셔틀콕이 가까워지면 팔을 휘두릅니다. 조금 일찍 휘둘러도 잠깐 기억했다가 칩니다.
- 위에서 아래로 내려치면 SMASH, 위로 크게 올려치면 CLEAR, 살짝 휘두르면 DROP, 옆으로 세게 휘두르면 DRIVE.
- 휘두를 때 손이 화면 왼쪽에 있으면 왼쪽으로, 오른쪽에 있으면 오른쪽으로 보냅니다.
- 카메라에 보이는 팔 각도가 3D 선수의 라켓 팔에 그대로 옮겨집니다.
- 설정: 내 이름(등 번호판과 점수판), 난이도, 점수(5·11·21), 1게임 또는 3게임(2선승), 라켓 손(오른손·왼손), 휘두름 감도(둔하게·보통·예민하게), 화질(자동·높음·보통·낮음).
- 휘둘러도 반응이 없으면 감도를 "예민하게", 가만히 있어도 쳐지면 "둔하게"로 바꿉니다. 게임 중에는 일시정지 화면에서 바꿀 수 있습니다.
- 화면이 끊기면 화질을 "낮음"으로 바꿉니다(빛 번짐·그림자·반사를 끄고 관중 수를 줄임).
- **화면 크기**: 카메라 화면(작게·보통·크게·숨기기), 글자·버튼 크기(작게·보통·크게·아주 크게), 전체 화면 버튼. 처음 화면과 일시정지 화면에서 바꾸고, 카메라 화면 위 「크기」 버튼으로도 바로 바꿉니다. 기기에 저장되어 다음에도 그대로입니다.
- **타격감**: 칠 때 여러 겹으로 합성한 타격음(날카로운 "딱" + 줄 울림 + "퍽" + 스매시 저음 "쾅"), 아주 짧은 멈춤(히트 스톱), 화면 흔들림, 스매시 번쩍임, 휴대폰 진동(안드로이드). 운동화 끽 소리, 관중 박수·환호·탄식, 심판 호루라기, 경기장 웅성거림. 소리 크기(끄기·작게·보통·크게)와 화면 흔들림(켜기·끄기)을 고를 수 있습니다.

## 파일

```
index.html        화면 틀과 HUD(점수판, 속도, 기술 카드, 메뉴)
js/main.js        입력(카메라·마우스·키보드), 점수판, 메뉴, 매 프레임 진행
js/game.js        경기 규칙, 셔틀콕 물리(실제 코트 규격, 공기 저항), 선수 이동, AI, 게임·세트
js/world.js       three.js 3D 경기장: 조명, 바닥 반사, 관중, LED 광고판, 심판석, 선수 모델과 동작, 셔틀콕 꼬리
js/tracking.js    MediaPipe Pose 로 팔 각도와 휘두름 인식, 손 인식 화면 그리기
js/audio.js       효과음 (Web Audio)
```

## 고칠 때

- 난이도 값은 `js/game.js` 의 `DIFF`, 휘두름 기준 속도는 `js/tracking.js` 의 `SWING_BASE`(어깨너비/초)입니다.
- 광고판 문구는 `js/world.js` 의 `words`에 있습니다. 실제 회사 상표는 넣지 않았습니다.
- 카메라 영상은 어디에도 보내지 않고 브라우저 안에서만 처리합니다.
- 예전 2D 버전은 Git 기록(커밋 `7bde554`)에 남아 있습니다.

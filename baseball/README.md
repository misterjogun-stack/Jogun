# 손 야구 (HAND BASEBALL)

카메라로 몸(어깨·팔꿈치·손목)을 인식해서, 방망이를 휘두르듯 팔을 휘두르면 투수가 던진 공을 치는 3D 야구 타격 게임입니다.

## 여는 방법

- **주소**: https://hand-baseball.vercel.app (Vercel 프로젝트 `hand-baseball`. 저장소와 자동 배포는 연결하지 않았으므로 고친 뒤에는 다시 배포해야 합니다)
- 휴대폰·태블릿을 세워 두고(세로·가로 모두 됨) 2미터쯤 떨어져 섭니다. 상체와 팔이 화면에 다 보여야 합니다.
- 처음 켤 때 3D 엔진(three.js)과 몸 인식 프로그램(MediaPipe Pose)을 받아서 10초쯤 걸립니다. 카메라는 https 주소에서만 켜집니다.
- ES 모듈이라 `index.html` 을 파일로 바로 열면 동작하지 않습니다. 웹 주소로 열거나 이 폴더에서 `python3 -m http.server` 로 띄웁니다.

## 노는 법

- 투수가 던진 공이 홈플레이트 앞 네모(스트라이크 존)에 올 때 옆으로 힘껏 휘두릅니다. 너무 빠르면 왼쪽(당겨치기), 늦으면 오른쪽으로 갑니다.
- 휘두른 뒤 아래쪽 타이밍 막대에 EARLY / PERFECT / LATE 가 표시됩니다.
- 스트라이크 존 둘레의 **타이밍 원**이 공이 다가올수록 줄어들고, 칠 순간에 초록색이 됩니다.
- **카메라 지연 보정**: 카메라로 몸을 알아보는 데 0.1~0.2초쯤 걸려서, 휘두름을 알아챈 시각에서 그만큼(`CAM_LEAD`, 0.12초)을 빼고 판정합니다. 공이 미트에 들어간 뒤 늦게 알아챈 휘두름도 0.3초 동안은 맞은 것으로 봅니다.
- **타이밍 자동 맞춤**(기본 켜짐): 카메라로 휘두를 때마다 늦거나 빠른 정도를 배워서 기기별 지연을 맞춥니다(최대 ±0.25초, 기기에 저장). 일시정지 화면에서 보정값을 보고 처음부터 다시 맞출 수 있습니다.
- 맞은 공은 실제 야구공처럼 공기 저항을 받으며 날아가고, 카메라가 공을 따라갑니다. 담장을 넘으면 홈런과 불꽃놀이.
- 점수: 홈런 1000점(+비거리×5), 3루타 500, 2루타 300, 안타 150, 아웃 30. 한 라운드는 공 10·20·30개.
- 마우스·터치: SWING 버튼이나 화면을 누릅니다. 키보드: 스페이스.

## 난이도

| | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 공 빠르기 | 72~83km/h | 94~112km/h | 115~137km/h |
| 공 종류 | 직구 | 직구·체인지업·커브 | 직구·체인지업·커브·슬라이더 |
| 맞힐 수 있는 시간 | ±0.2초 | ±0.14초 | ±0.1초 |
| 담장 | 78~96m | 88~108m | 98~120m |

난이도를 바꾸면 담장 거리가 달라서 경기장을 새로 불러옵니다.

## 설정

내 이름(등 번호판·점수판), 공 개수, 휘두르는 손, 휘두름 감도, 소리 크기, 카메라 화면 크기, 경기 화면 거리(마우스 휠로도 조절), 글자·버튼 크기, 화질, 전체 화면. 일시정지 화면에서 화면 흔들림도 끌 수 있습니다.

## 파일

```
index.html        화면 틀과 HUD(점수판, 구속·타구 속도, 이번 라운드 기록, 타이밍 막대, SWING 버튼, 메뉴)
js/main.js        입력, 점수판, 메뉴, 매 프레임 진행
js/game.js        투구(구종·속도·목표 지점), 타이밍 판정, 타구 물리, 안타·홈런 판정, 점수
js/world.js       three.js 야간 야구장: 잔디·내야 흙, 담장과 거리 표시, 관중석, 조명탑, 전광판, 타자·투수·수비수, 불꽃놀이
js/tracking.js    MediaPipe Pose 휘두름 인식 (손 배드민턴과 같은 코드)
js/audio.js       효과음: 방망이 "딱", 미트 "퍽", 관중, 불꽃놀이 (Web Audio 합성)
```

카메라 영상은 어디에도 보내지 않고 브라우저 안에서만 처리합니다.

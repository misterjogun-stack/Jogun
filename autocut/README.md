# AutoCut

영상을 올리면 군더더기를 자르고, 자막을 입히고, 세로(9:16)로 맞춰 완성본을 만들어 주는 웹앱입니다. 업종에 상관없이 쓸 수 있게 만들었고, 업종별로는 AI에게 주는 편집 지침과 게시물 글 말투만 달라집니다.

## 어떻게 동작하나

```
업로드 → 음성 인식(단어별 시간) → 말 덩어리로 묶기 → 편집 계획 → ffmpeg 렌더링 → 완성본
```

1. **음성 인식**: faster-whisper가 말을 단어 단위 시간과 함께 글자로 바꿉니다.
2. **말 덩어리(phrase)**: 쉬는 구간·문장 끝·글자 수 기준으로 묶습니다. 자막 한 줄이자 컷의 최소 단위입니다.
3. **편집 계획**: Claude가 번호 붙은 말 덩어리 중 *남길 번호*만 고르고, 오인식 수정·강조 단어·게시물 글·해시태그를 냅니다. 시간은 번호에서 계산하므로 AI가 시간을 지어낼 수 없습니다.
4. **렌더링**: ffmpeg가 컷 편집, 비율 변환, 자막 합성, 컷 경계 페이드, 음량 정리를 한 번에 합니다.

`ANTHROPIC_API_KEY`가 없거나 AI 호출이 실패하면 규칙 기반(무음 제거 + 자동 자막)으로 대체하고, 결과 화면에 그 사실을 표시합니다.

## 실행

필요한 것: Python 3.10+, ffmpeg(libass 포함), 한글 폰트.

```bash
cd autocut
pip install -r requirements.txt

# 한글 자막 폰트(Noto Sans KR)를 fonts/ 에 넣습니다. 폰트 이름은 AUTOCUT_FONT_NAME으로 바꿀 수 있습니다.
curl -L -o fonts/NotoSansKR.ttf "https://raw.githubusercontent.com/google/fonts/main/ofl/notosanskr/NotoSansKR%5Bwght%5D.ttf"

export ANTHROPIC_API_KEY=...        # 없으면 규칙 기반 편집
uvicorn app.main:app --port 8000    # http://localhost:8000
```

첫 실행 때 Whisper 모델을 내려받습니다(small 기준 약 500MB). 정확도가 더 필요하면 `AUTOCUT_WHISPER=large-v3`.

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 없음 | 편집 계획용 AI 키 |
| `AUTOCUT_MODEL` | `claude-sonnet-5-5` | 편집 계획 모델 |
| `AUTOCUT_WHISPER` | `small` | 음성 인식 모델 크기 |
| `AUTOCUT_FONT_NAME` | `Noto Sans KR` | 자막 폰트 이름 |
| `AUTOCUT_MAX_UPLOAD_MB` | `1024` | 업로드 한도 |
| `AUTOCUT_JOB_TTL_HOURS` | `24` | 작업 파일 보관 시간 |

## 말로 고치기

완성된 영상 아래 입력칸에 말로 요청하면 새 버전을 만듭니다. **한 번에 하나씩** 말하세요. 어떤 수정 때문에 달라졌는지 알 수 있어요. 수정 기록에서 **되돌리기 / 다시 적용**을 할 수 있고, 되돌린 뒤 새로 고치면 그 뒤 기록은 사라집니다.

| 말 | 하는 일 |
|---|---|
| `12초에서 15초 사이 잘린 부분 다시 살려 줘` | 원본 12~15초를 되살리고 그 구간 자막도 되살림 |
| `20초에서 22초는 잘라 줘` | 원본 20~22초 삭제 |
| `마지막 2초는 잘라 줘` / `처음 1초 잘라 줘` | 완성본 기준으로 앞뒤 자르기 |
| `배경음악 조금 더 줄여 줘` / `많이 줄여` / `키워` / `꺼 줘` | 말소리 대비 음량 조절(기본 0.25, 조금 = ×0.75, 많이 = ×0.5) |
| `자막 글자색을 노란색으로 바꿔 줘` | 색 이름 또는 `#RRGGBB` |

- 구간(살리기, 자르기)은 **원본 영상 시간**, 앞뒤 자르기는 **완성본 시간** 기준입니다.
- 배경음악은 처음 올릴 때 파일을 함께 올려야 들어갑니다(짧으면 반복, 끝에서 1초 페이드아웃). 음량 조절은 배경음악이 있는 영상에서만 들립니다.
- 제목 글자, 새 효과, 순서 바꾸기처럼 **아직 없는 기능은 지어내지 않고** 이유를 알려줍니다.
- `ANTHROPIC_API_KEY`가 있으면 Claude가 문장을 해석하고(더 다양한 표현 가능), 없거나 실패하면 위 표의 표현을 규칙으로 해석합니다.

## 레퍼런스 분석

마음에 드는 영상의 색감과 컷 속도를 재서 어울리는 룩을 추천합니다.

```bash
python tools/analyze_reference.py 레퍼런스/                      # 폴더 안 영상 전부
python tools/analyze_reference.py a.mov --trim-right 0.18      # 오른쪽 버튼 영역 제외
```

화면 녹화처럼 검은 띠가 있어도 영상 영역만 찾아 잽니다. 추천 기준은 눈으로 본 레퍼런스 2종에서 정한 단순한 규칙이라 참고용이에요.
일부 사이트는 자동 다운로드를 막습니다. 그럴 땐 영상을 직접 저장해 `레퍼런스/` 폴더에 넣으세요.

## 저작권과 라이선스

- **받은 영상은 참고용**입니다. 남의 영상은 스타일 분석에만 쓰고, 그 장면을 내 영상에 넣거나 다시 올리지 마세요. 저작권과 각 플랫폼 약관이 적용됩니다.
- **배경음악도 저작권 걱정 없는 곡**을 쓰세요.
- 이 앱이 쓰는 것: faster-whisper(MIT), FFmpeg(LGPL/GPL, 외부 프로그램으로 호출), Noto Sans KR 폰트(SIL OFL), Anthropic API(해당 약관). 회사에서 쓰거나 배포할 때는 각 라이선스를 직접 확인하세요. 이 문서는 법률 자문이 아닙니다.
- Remotion, HyperFrames는 쓰지 않습니다(ffmpeg만 사용).

## 룩(분위기)

화면의 `분위기` 옵션으로 색감과 자막 스타일을 함께 고릅니다(`app/looks.py`).

- **기본**: 또렷한 큰 노랑 자막.
- **시네마틱**: 광고 영상 레퍼런스에서 측정한 값을 옮긴 것. 그림자는 차가운 푸른빛, 검정은 살짝 띄우고, 자막은 작은 흰 글씨에 핵심 단어만 호박색으로 크게. 색보정은 ffmpeg 필터(`curves`, `eq`, `colorbalance`)라 영상마다 결과가 조금 다릅니다. 촬영 조명과 렌즈가 만드는 분위기를 보정만으로 똑같이 만들 수는 없습니다.

- **아침 햇살(airy)**: 밝고 공기 같은 광고 느낌. 밝은 부분을 흐려 번지게 하고(블룸), 따뜻한 크림빛에 청록빛 그림자. 자막은 화면 옆쪽 중간보다 약간 아래에 작고 연하게, 천천히 나타났다 사라집니다. 레퍼런스 광고의 측정값(평균 R−B +17, 검정 0.16, 상위 5% 밝기 0.92, 날아간 하이라이트 3.6%, 채도 0.20)을 목표로 맞췄습니다. 푸른 하늘이 큰 야외 영상은 따뜻한 쪽으로 전부 옮겨지지는 않습니다.

새 룩을 추가하려면 `looks.py`의 `GRAPH`에 필터 그래프 조각(입력 `{i}`, 출력 `{o}`)을 넣고 `LOOKS`에 이름을 더하면 됩니다.

## 현재 한계와 다음 단계

- 작업 상태는 서버 메모리에 있어서 서버를 재시작하면 진행 중이던 작업은 사라집니다.
- 로그인이 없습니다. 인터넷에 공개하려면 로그인·사용량 제한을 먼저 붙여야 합니다(업로드와 렌더링은 서버 자원을 많이 씁니다).
- 편집은 말 중심입니다. 말이 거의 없는 영상은 원본 전체를 비율만 바꿔 내보냅니다. 장면 전환 감지, 배경음악, 효과음, 3분할 합성은 아직 없습니다.
- 자막 문구를 직접 고치거나 컷 경계를 끌어서 조정하는 화면은 없습니다(말로 고치기만 가능). 계획은 작업 폴더의 `plan_v*.json`에 버전별로 저장됩니다.
- 말 순서를 바꾸는 편집(훅을 앞으로 당기기)은 하지 않고 시간순으로만 자릅니다.

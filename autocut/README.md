# AutoCut

촬영본을 넣으면 **말 없는 구간을 자르고, 자막과 제목 모션을 입히고, 배경음악을 깔아** 세로 1080×1920 영상으로 만들어 주는 앱입니다. 마음에 드는 영상을 레퍼런스로 주면 색감과 리듬을 재서 «내 스타일.md»로 정리하고, 그 스타일대로 편집합니다. 결과는 말로 고칠 수 있습니다("자막 더 크게 해 줘").

쓰는 방법은 두 가지예요.

- **웹앱**: 브라우저에서 영상 올리기 → 완성본 보기 → 말로 고치기 → 다운로드
- **폴더 모드**: `원본 / 레퍼런스 / 완성본` 폴더에 넣고 명령 한 줄

## 1. 설치

필요한 것: Python 3.10+, FFmpeg(libass 포함), 한글 폰트.

```bash
cd autocut
pip install -r requirements.txt
curl -L -o fonts/NotoSansKR.ttf "https://raw.githubusercontent.com/google/fonts/main/ofl/notosanskr/NotoSansKR%5Bwght%5D.ttf"
python -m app.doctor        # 도구가 다 깔렸는지 표로 확인
```

FFmpeg: 맥 `brew install ffmpeg`, 윈도우 `winget install Gyan.FFmpeg`.
첫 실행 때 Whisper 음성 인식 모델을 내려받습니다(small 기준 약 500MB). 느리면 `AUTOCUT_WHISPER=small`(기본), 정확도가 더 필요하면 `large-v3`.

`ANTHROPIC_API_KEY`를 넣으면 Claude가 편집 계획을 짜고(군더더기·반복 자르기, 오인식 고치기, 게시물 글), 고치기 요청을 해석하고, 레퍼런스의 자막 위치·글꼴·전환·분위기를 글로 정리합니다. 없으면 무음 제거와 자동 자막, 정해진 표현의 고치기만 됩니다.

## 2. 폴더 모드 — 폴더 셋, 명령 한 줄

```
AI 영상 편집/
  원본/        내가 찍은 촬영본 + 깔고 싶은 배경음악(mp3·m4a·wav, 첫 번째 파일 사용)
  레퍼런스/     마음에 드는 영상(직접 저장한 파일)
  완성본/      결과가 여기로 나와요
  내 스타일.md  레퍼런스를 분석해 자동으로 만들어져요
```

```bash
python -m app.folder "~/Desktop/AI 영상 편집" --title "봄 펌 추천"
python -m app.folder "~/Desktop/AI 영상 편집" --preview 60        # 먼저 앞 1분만 시험
python -m app.folder "~/Desktop/AI 영상 편집" --restyle           # 레퍼런스를 바꿨을 때 스타일 다시 만들기
```

폴더가 없으면 만들어 줍니다. 촬영본마다 완성본 폴더에 세 파일이 나옵니다.

| 파일 | 내용 |
|---|---|
| `<이름>_편집.mp4` | 완성본(세로 1080×1920) |
| `<이름>_자막.srt` | 완성본 시간에 맞춘 자막 |
| `<이름>_잘린부분.txt` | 어디를 얼마나 잘랐는지(원본 기준 시간) |

## 3. 웹앱

```bash
uvicorn app.main:app --port 8000    # http://localhost:8000
```

영상, 배경음악(선택), 제목(선택), 분위기, 화면 비율을 고르고 시작합니다. "먼저 앞 1분만 시험해 보기"로 긴 영상을 빠르게 확인할 수 있어요. 결과 화면에서 **잘린 부분 목록**, **말로 고치기**, **자막 보기·고치기**(틀린 글자 고친 뒤 다시 입히기), **SRT 받기**를 할 수 있습니다.

## 4. 레퍼런스 — «영감만»

레퍼런스는 **리듬과 분위기만** 가져옵니다. 장면·문구·그래픽은 따라 하지 않아요. «내 스타일.md»에는 다음이 들어갑니다.

- 맨 위 설정 블록의 `look:` 값(`none` / `cinematic` / `airy`). **직접 고치면 다음 편집부터 그 룩을 씁니다.**
- 측정값: 컷 평균 간격, 평균 색온도(R−B), 그림자 색, 밝기 범위, 날아간 하이라이트 비율, 채도
- (API 키가 있으면) 자막 위치·글꼴 느낌·화면 전환·제목 모션·분위기 설명

레퍼런스 고르는 요령: 내가 찍는 영상과 **비슷한 길이·형식**(예: 세로 영상끼리)으로 고르면 결과가 안정적이에요. 분위기가 제각각인 영상을 섞으면 스타일도 섞여 나와요.

분석만 따로 할 때:

```bash
python tools/analyze_reference.py 레퍼런스/
python tools/analyze_reference.py 화면녹화.mov --trim-right 0.18   # 오른쪽 좋아요·댓글 버튼 영역 제외
```

화면 녹화처럼 위아래 검은 띠가 있어도 영상 영역만 찾아서 잽니다.

## 5. 편집 기준

| 항목 | 기준 |
|---|---|
| 무음 자르기 | 말 사이가 약 0.4초 넘게 비면 자름(말 앞뒤에 0.1~0.18초 여유) |
| 자막 | 한 줄 16자 이내, 두 줄까지 |
| 제목 모션 | 첫 3초. 룩마다 다름(기본: 튀어나옴 / 시네마틱: 자간이 넓어짐 / 아침 햇살: 떠오름) |
| 배경음악 | 말소리 대비 0.25(약 −12dB), 짧으면 반복, 끝에서 1초 페이드아웃 |
| 내보내기 | 세로 1080×1920 mp4(H.264, AAC), 음량 정리 |

### 룩(분위기)

| 룩 | 색감 | 자막 |
|---|---|---|
| 기본 | 원본 그대로 | 아래쪽, 크고 굵은 노란 글씨 |
| 시네마틱 | 그림자는 푸른빛, 검정은 살짝 띄움 | 아래쪽 작은 흰 글씨, 핵심 단어만 호박색 |
| 아침 햇살 | 밝은 부분이 번지고 따뜻한 크림빛 | 옆쪽 중간보다 약간 아래, 작고 연하게 천천히 |

색보정은 영상마다 결과가 조금 다르고, 촬영 조명·렌즈가 만드는 분위기를 보정만으로 똑같이 만들 수는 없습니다. 새 룩은 `app/looks.py`의 `GRAPH`에 필터 그래프 조각(입력 `{i}`, 출력 `{o}`)을 넣고 `LOOKS`에 이름을 더하면 됩니다.

## 6. 말로 고치기 — 한 번에 하나씩

한 번에 하나씩 말하세요. 어느 수정 때문에 달라졌는지 알 수 있어요. 수정마다 새 버전이 생기고 **되돌리기 / 다시 적용**이 됩니다.

| 말 | 하는 일 |
|---|---|
| `자막 더 크게 해 줘` / `많이 크게` / `조금 작게` | 자막 크기 ×1.2 / ×1.4 / ×0.85 (0.6~1.8배) |
| `12초에서 15초 사이 잘린 부분 다시 살려 줘` | 원본 12~15초와 그 구간 자막 되살리기 |
| `20초에서 22초는 잘라 줘` | 원본 20~22초 삭제 |
| `마지막 2초는 잘라 줘` / `처음 1초 잘라 줘` | 완성본 기준 앞뒤 자르기 |
| `배경음악 조금 더 줄여 줘` / `많이 줄여` / `키워` / `꺼 줘` | 배경음악 음량(×0.75 / ×0.5 / ×1.3 / 끄기) |
| `자막 글자색을 노란색으로 바꿔 줘` | 색 이름 또는 `#RRGGBB` |
| `제목 글자색을 노란색으로 바꿔 줘` | 제목 색 |
| `제목을 "봄 펌 추천"으로 바꿔 줘` / `제목 빼 줘` | 제목 문구(따옴표 안) |

- 구간(살리기·자르기)은 **원본 영상 시간**, 앞뒤 자르기는 **완성본 시간** 기준입니다.
- 한 문장에 둘을 말해도("제목 글자색을 노란색으로 바꾸고, 마지막 2초는 잘라 줘") 나눠서 처리하지만, 하나씩이 확인하기 쉽습니다.
- 없는 기능(새 효과, 순서 바꾸기 등)은 지어내지 않고 이유를 알려줍니다.
- 자막 글자가 틀리면 결과 화면의 **자막 보기·고치기**에서 고친 뒤 저장하세요.

## 7. 알아 두면 좋은 것

- **받은 영상은 참고용**: 남의 영상은 스타일 분석에만 쓰고, 그 장면을 내 영상에 넣거나 다시 올리지 마세요. 저작권과 각 플랫폼 약관이 적용됩니다. 배경음악도 저작권 걱정 없는 곡을 쓰세요.
- **레퍼런스 자동 다운로드(yt-dlp)는 넣지 않았습니다.** 여러 플랫폼이 약관으로 자동 수집을 막고 있어서, 영상을 직접 저장해 `레퍼런스/` 폴더에 넣는 방식만 지원합니다.
- **Remotion, HyperFrames는 쓰지 않습니다.** 제목 모션은 FFmpeg의 자막 엔진(libass) 애니메이션으로 만듭니다. 그래서 Node.js가 필요 없고, Remotion의 회사 라이선스(4인 이상 유료) 문제도 없습니다. 그래프·복잡한 화면 전환 같은 모션 그래픽은 아직 없습니다.
- **라이선스**: faster-whisper(MIT), FFmpeg(LGPL/GPL, 외부 프로그램으로 호출), Noto Sans KR(SIL OFL), Anthropic API(해당 약관). 회사에서 쓰거나 배포할 때는 각 라이선스를 직접 확인하세요. 이 문서는 법률 자문이 아닙니다.

## 환경 변수

| 이름 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 없음 | AI 편집 계획·고치기 해석·레퍼런스 설명 |
| `AUTOCUT_MODEL` | `claude-sonnet-5-5` | 위 작업에 쓰는 모델 |
| `AUTOCUT_WHISPER` | `small` | 음성 인식 모델 크기 |
| `AUTOCUT_FONT_NAME` | `Noto Sans KR` | 자막 폰트 이름 |
| `AUTOCUT_MAX_UPLOAD_MB` | `1024` | 웹 업로드 한도 |
| `AUTOCUT_JOB_TTL_HOURS` | `24` | 웹 작업 파일 보관 시간 |

## 동작 방식

```
업로드/원본 → 음성 인식(단어별 시간) → 말 덩어리로 묶기 → 편집 계획(Claude 또는 규칙)
           → ffmpeg: 컷 + 비율 + 룩(색보정) + 자막·제목 모션 + 배경음악 + 음량 정리 → 완성본
```

Claude는 번호 붙은 말 덩어리 중 남길 번호만 고릅니다. 시간은 번호에서 계산하므로 AI가 시간을 지어낼 수 없습니다.

## 현재 한계

- 웹앱의 작업 상태와 수정 기록은 서버 메모리에 있어서 서버를 재시작하면 사라집니다.
- 로그인이 없습니다. 인터넷에 공개하려면 로그인·사용량 제한을 먼저 붙여야 합니다.
- 편집은 말 중심입니다. 말이 거의 없는 영상은 원본 전체를 룩만 입혀 내보냅니다. 여러 클립을 리듬에 맞춰 이어 붙이는 편집은 아직 없습니다.
- 컷 경계를 끌어서 조정하는 화면은 없습니다(말로 고치기와 자막 글자 수정만 가능).

# 폰 점검 체크리스트 (약 10분)

자동 테스트로 확인할 수 없었던 부분을 실제 폰에서 확인하는 순서입니다.
**아이폰 1대, 안드로이드 1대**에서 해 보면 가장 좋습니다. 하나만 있으면 그 폰으로만 해도 됩니다.

문제가 보이면 **화면 캡처(또는 화면 녹화) + 폰 기종 + 브라우저 이름(사파리, 크롬, 카톡 안에서 열기 등)** 만 보내 주세요.

---

## 0. 준비 (1분)
- [ ] 새 주소 **zerocount.vercel.app** 을 연다.
- [ ] 옛 주소(filo-salon-system.vercel.app)로 앱을 쓰던 폰이면, 옛 주소를 한 번 열고 위쪽의 **'기록 가지고 새 주소로 이동'** 을 누른다.
  - 확인: 새 창에 내 품목이 그대로 보이고 "옛 주소의 기록을 그대로 옮겨 왔습니다"가 뜬다.

## 1. 홈 화면에 추가 (1분)
- **아이폰:** 사파리 아래쪽 공유 버튼 → '홈 화면에 추가'
- **안드로이드:** 크롬 오른쪽 위 ⋮ → '홈 화면에 추가' 또는 '앱 설치'
- [ ] 홈 화면 아이콘이 **검은 바탕의 Z 로고**이고, 이름이 **ZEROCOUNT** 로 보인다.
- [ ] 아이콘으로 열면 주소창 없이 앱처럼 열린다.
- [ ] 옛 주소로 추가해 둔 아이콘이 있으면 지운다.

## 2. 카메라 바코드 스캔 (2분)
1. 재고조사 → **재고조사 생성** → **바코드 스캔으로 조사하기**
2. 카메라 권한을 묻으면 **허용**
- [ ] 카메라 화면이 뜬다. 안 뜨면 화면에 나온 안내 문구를 캡처해 주세요.
- [ ] 바코드를 화면의 흰 테두리 안에, **10~20cm** 거리에서 비추면 1~2초 안에 인식된다.
- [ ] 등록된 바코드면 품목 이름과 + − 칸이 뜨고, **등록하기**를 누르면 목록의 '실물' 칸에 들어간다.
- [ ] 등록되지 않은 바코드면 **'이 바코드로 품목 등록'** 버튼이 뜬다.
- 잘 안 읽힐 때: 조명을 밝게 하거나, 바코드를 조금 멀리 해서 다시 시도해 보세요. 그래도 안 되면 그 바코드 사진을 보내 주세요.
- 다 해 본 뒤 조사는 **조사 완료 → 기록만 남기고 완료**로 끝내면 재고가 바뀌지 않습니다.

## 3. 바코드 라벨 인쇄 (3분)
1. 품목 관리 → **바코드 라벨 출력** → 라벨지 종류 선택 → **라벨 출력**
2. 인쇄 창에서 **용지 A4 · 배율 '실제 크기(100%)' · 여백 '없음'**
- [ ] **처음엔 일반 A4 종이에 인쇄**해서, 갖고 있는 라벨지 위에 겹쳐 대 보고 칸이 맞는지 본다.
  - 맞지 않으면: 라벨지 포장에 적힌 제품명이나 한 칸의 가로·세로 크기(mm), 칸 수를 알려 주세요. 그 라벨지에 맞게 바꿔 드립니다.
- [ ] 라벨 하나를 약통에 붙이고 2번처럼 카메라로 찍어서 인식되는지 본다.

## 4. 카톡 공유 미리보기 (1분)
- [ ] 카톡 '나와의 채팅'에 **https://zerocount.vercel.app** 을 붙여 넣는다.
- [ ] Z 로고와 '정확한 재고조사, 더 스마트하게'가 들어간 미리보기가 뜬다.
  - 예전 이미지나 빈 미리보기가 뜨면 카톡이 예전 것을 기억하고 있는 경우입니다. 하루쯤 지나 다시 확인해 보세요.

## 5. 빠른 차감 정정 (1분)
- [ ] 빠른 차감에서 아무 약이나 **+ 두 번 → − 두 번** 누른다. 위쪽 '오늘 사용' 숫자가 **그대로**인지 본다.
- [ ] − 한 번 누른 뒤 **되돌리기**를 누르면 '오늘 사용'이 다시 원래대로 돌아온다.

## 6. 오프라인 (1분)
- [ ] 앱을 한 번 연 상태에서 **비행기 모드**를 켜고 앱을 닫았다가 다시 연다. 앱과 내 기록이 그대로 보인다.
- [ ] 비행기 모드를 끈다.

## 7. 백업 (1분)
- [ ] 설정 → **↓ 전체 백업** → 받은 파일을 카톡 '나와의 채팅'으로 보낸다.
- [ ] (선택) 다른 폰이나 다른 브라우저에서 앱을 열고, 설정 → **↑ 백업 복원**으로 그 파일을 열어 기록이 그대로 들어오는지 본다.

## 8. 엑셀 (선택, 2분)
- [ ] 품목 관리 → **엑셀 양식 받기** → 엑셀이나 구글 시트에서 열어 한 줄 추가 → 저장 → **엑셀 · CSV 업로드**
- [ ] 미리보기에 '추가 1'이 보이고, 적용하면 목록에 생긴다.

### 결과 보내는 방법
아래처럼 짧게 보내 주시면 됩니다.

```
아이폰 15 / 사파리
1 홈화면 ✅  2 카메라 ✅  3 라벨 ❌ (칸이 아래로 밀림, 사진 첨부)  4 카톡 ✅
5 ✅  6 ✅  7 ✅  8 안 해봄
```

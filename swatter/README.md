# 손 파리채 (HAND SWATTER)

카메라로 손을 인식해서, 손이 파리채가 되어 화면 속 파리·모기를 "찰싹" 잡는 게임입니다. 카메라 화면 위에 귀여운 만화풍 벌레가 날아다닙니다. 3D 가 아니라 2D 라서 휴대폰에서도 가볍게 돌아갑니다.

## 여는 방법

- **주소**: https://hand-swatter.vercel.app (Vercel 프로젝트 `hand-swatter`. 저장소와 자동 배포는 연결하지 않았으므로 고친 뒤에는 다시 배포해야 합니다)
- 휴대폰·태블릿을 세워 두고 1~2미터 떨어져 섭니다. 손이 화면에 보이면 손 자리에 파리채가 생깁니다.
- 처음 켤 때 손 인식 프로그램(MediaPipe Hands)을 받아서 10초쯤 걸립니다. 카메라는 https 주소에서만 켜집니다.
- ES 모듈이라 `index.html` 을 파일로 바로 열면 동작하지 않습니다. 웹 주소로 열거나 이 폴더에서 `python3 -m http.server` 로 띄웁니다.

## 노는 법

- 벌레 위에서 손을 빠르게 휘두르면 찰싹! 파리채 그물 안에 들어온 벌레를 잡습니다. 한 번에 여러 마리 잡으면 DOUBLE·TRIPLE.
- 파리채를 천천히 가까이 대면 파리가 도망갑니다(보통·어려움).
- 연달아 잡으면 콤보: 3마리마다 점수 배수가 올라 최대 5배. 2.2초 동안 못 잡으면 콤보가 끊깁니다.
- 마우스·터치: 벌레를 누르면 찰싹. 키보드 스페이스는 마우스 자리를 찰싹.

| 벌레 | 움직임 | 점수 |
|---|---|---|
| 파리 | 지그재그로 날다가 수박·케이크에 잠깐 앉음 | 100 |
| 모기 | "애앵" 소리를 내며 점점 커지면서 얼굴(화면 가운데)로 옴. 놓치면 물려서 −50, 빨간 자국 | 150 |
| 왕파리 | 크고 느리지만 두 번 맞아야 잡힘 (한 번 맞으면 어질어질) | 300 |
| 꿀벌 | 잡으면 안 됨 | −200 |
| 황금 파리 | 가끔 나오고 빠름. 잡으면 6초 동안 점수 2배 | 1000 |
| 파리왕 (보스) | 왕관을 쓴 큰 파리. 여러 번 때려야 하고 작은 파리를 계속 부름 | 3000 + 남은 시간 보너스 |

## 스테이지와 설정

- 스테이지: 부엌(수박·케이크), 캠핑장 밤(모기·랜턴), 피크닉(꿀벌 섞임), 파리왕(보스).
- 인원: 혼자, 또는 둘이서 대결(화면 왼쪽 1P 파랑, 오른쪽 2P 주황. 손이 있는 쪽의 점수가 됩니다).
- 시간: 30·60·90초. 난이도: 쉬움(느리고 적게, 도망 없음)·보통·어려움(파리왕 체력도 늘어남).
- 혼자 할 때는 스테이지·난이도·시간별 최고 기록을 기기에 저장합니다.
- 휘두름 감도, 소리 크기, 글자·버튼 크기, 화면 흔들림, 전체 화면.

## 파일

```
index.html      화면 틀과 HUD(점수, 남은 시간, 콤보, 황금 시간, 파리왕 체력, 메뉴)
js/main.js      카메라 화면 그리기, 입력(손·마우스·키보드), 효과음 연결, 기록
js/game.js      벌레 종류별 움직임, 찰싹 판정(카메라 지연을 생각해 0.12초 전 위치도 봄), 콤보·점수, 벌레·소품·파리채 그리기
js/hands.js     MediaPipe Hand Landmarker 로 손 최대 4개를 따라가고 빠른 손짓을 찰싹으로 알아챔
js/audio.js     효과음 합성: 찰싹, 뿅, 윙윙(파리·모기·꿀벌 날갯소리, 좌우 위치), 물림, 콤보, 시간 끝
```

카메라 영상은 어디에도 보내지 않고 브라우저 안에서만 처리합니다.

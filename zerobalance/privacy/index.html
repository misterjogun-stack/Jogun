한 줄 요약

입력한 매출·지출·직원 급여는 내가 쓰는 기기 안에만 저장돼요. 운영자(제작자)에게도, 다른 회사 서버에도 보내지 않아요.

1. 어디에 저장되나요?

앱에 입력한 모든 기록은 지금 쓰는 기기의 브라우저 저장 공간에 보관돼요. 서버에 올라가지 않아요.

  • 매출·지출·손님 수, 직원 이름과 급여 입력, 매장 설정
  • 잠금을 켠 경우: 비밀번호(원래 숫자가 아닌 변환한 값)와 내가 적은 힌트

그래서 기기를 잃어버리거나 브라우저 데이터를 지우면 기록도 사라져요. 앱의 더보기 › 기기 맞추기 · 백업으로 파일을 만들어 따로 보관해 주세요.

2. 밖으로 나가는 것이 있나요?

입력한 기록은 밖으로 나가지 않아요. 다만 화면을 보여 주려고 아래 접속은 일어나요.

  • 사이트 제공(Vercel): 앱 파일을 내려받을 때 일반적인 접속 기록(접속 시각, IP 주소 등)이 호스팅 회사에 남을 수 있어요.
  • 글꼴(jsDelivr): 예쁜 글꼴을 불러오려고 글꼴 배포 서비스에 접속해요. 이때도 접속한 기기의 IP 주소 같은 일반 정보가 그쪽에 보일 수 있어요.

앱 안에는 광고, 분석 도구, 외부 로그인이 없어요.

3. 내가 직접 보내는 것

  • 백업·정산 이미지: 내가 직접 카톡이나 문자로 보내는 곳으로만 가요.
  • 문의·의견: ‘문의 · 개선 제안’을 누르면 적은 내용과 앱 버전·기기 종류가 복사되고 인스타그램 DM이 열려요. 보내기 전에 내용을 확인할 수 있고, 매출 같은 숫자는 함께 보내지 않아요. 인스타그램에서의 처리는 인스타그램 정책을 따라요.

4. 잠금 기능은 어떤 보호를 하나요?

비밀번호 잠금은 다른 사람이 화면을 넘겨보지 못하게 가려 주는 기능이에요. 기록 자체를 암호화하지는 않아요.

비밀번호를 잊으면 찾아 드릴 수 없어요. 힌트로도 못 찾으면 이 기기의 기록을 지워야 풀 수 있어요.

5. 기록 지우기

  • 앱 설정 › 전체 데이터 지우기를 누르면 이 기기의 기록이 모두 지워져요.
  • 브라우저의 사이트 데이터를 지워도 같은 효과예요.
  • 다른 곳에 저장해 둔 백업 파일은 직접 삭제해 주세요.

6. 직원 정보를 입력할 때

직원 이름·급여를 입력하는 경우 그 정보는 내 기기 안에만 보관돼요. 정산내역 이미지나 문자를 직원에게 보낼 때는 해당 직원에게만 보내 주세요.

7. 세금·급여 계산에 대해

앱이 보여 주는 세금과 급여 금액은 입력한 숫자로 계산한 추정치이고, 세무·노무 자문이 아니에요. 세율과 요율은 해마다 바뀔 수 있어요. 실제 신고와 지급 전에는 세무사 등 전문가와 확인해 주세요.
